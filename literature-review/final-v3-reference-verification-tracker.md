# Final v3 Reference Verification Tracker

## Purpose

This tracker is for verifying every reference before submitting the RA-MARS v3 manuscript.

## Final Manuscript

Use references from:

- `literature-review/final-v3-reference-list-extracted.md`

## Verification Checklist

For every reference, verify:

- [ ] Author names
- [ ] Article title
- [ ] Journal or conference name
- [ ] Year
- [ ] Volume
- [ ] Issue
- [ ] Page range or article number
- [ ] DOI
- [ ] Publisher page availability
- [ ] In-text citation exists
- [ ] Reference is not duplicated
- [ ] Reference supports the claim where cited

## Trusted Sources

Use only trusted sources for verification:

- Publisher page
- IEEE Xplore
- ScienceDirect
- SpringerLink
- ACM Digital Library
- Wiley Online Library
- MDPI official article page
- Nature/Springer official article page
- DOI.org / Crossref

## Rules

- Do not keep unverifiable references.
- Do not use fake or weak references only to increase count.
- Do not overuse one publisher if avoidable.
- Keep references relevant to UAV security, jamming, spoofing, mission assurance, resilience, digital twins, and tamper-resistant logging.
- Final references should match Elsevier numbered style.
